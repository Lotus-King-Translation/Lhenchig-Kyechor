# Translation artifacts

Canonical English: [paired/translation.md](../paired/translation.md). [RUN.md](RUN.md) pins the inputs and scope. [NOTES.md](NOTES.md) and [USAGE.md](USAGE.md) are generated from authored JSON records. [proposed-glossary.csv](proposed-glossary.csv) contains inactive eight-column proposals; the active glossary is unchanged.

[QC](qc/README.md) separates translator self-check, independent source review and verification of applied changes. [Coverage](../paired/coverage.json) distinguishes represented source, annotated interpretations and retained unresolved Tibetan. Working-release signoff is limited to this documented scope. Source and terminology questions remain visible for human/source review.
